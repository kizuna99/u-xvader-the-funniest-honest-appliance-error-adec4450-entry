# The Funniest Honest Appliance Error — entry

A make.fun entry for **The Funniest Honest Appliance Error**: one line of at most
200 characters — the funniest honest error message an appliance could show.

The entry line:

> ERROR: Drain blocked. I am sitting in your grey water. I have seen what was in your pockets. We will not discuss it.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (falling back to `./output/entry.txt`
outside the grading sandbox).
